How it works

From question to completion.

Every task follows the same three stages, whether it is a first-week onboarding question or a once-a-year approval.

  1. Ask

    Describe the task

    Ask in plain language, the way you would ask a colleague.

    We need a laptop for a contractor starting Monday

  2. Navigate

    Get a structured path

    See the applicable steps, the decisions that matter and the sources behind them.

    Check eligibilityContractor?Sponsor approval

  3. Act

    Move the work forward

    Complete each step, confirm what is required and know what remains.
